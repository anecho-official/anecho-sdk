# Anecho SDK

Primary-speaker isolation that runs in **your** process: 16 kHz, 15 ms of
algorithmic delay, 5.3 MB model, real-time on one CPU core. Audio never leaves
the process — the SDK reports processed durations only, and that heartbeat is
what keeps your licence token fresh.

Get an API key and your model file at https://app.anecho.ai — docs at
https://anecho.ai/docs/sdk.
